# 제품 브리프 — 쇼핑몰 화면 (상품 목록 + 장바구니)

## 목표

작은 온라인 쇼핑몰의 첫 화면을 만든다. 손님이 상품을 둘러보고 장바구니에 담아 결제 금액을 확인할 수 있으면 된다.
결제·로그인·서버는 범위 밖이다.

## 꼭 필요한 것

- 상품 목록: 이미지 자리, 상품명, 가격, 할인 중이면 할인율과 할인가, 품절 표시
- 정렬: 추천순(기본) · 낮은 가격순 · 높은 가격순
- 장바구니 담기: 품절 상품은 담을 수 없다
- 장바구니: 수량 변경, 삭제, 상품 금액 합계, 배송비, 결제 예정 금액
- 배송비 정책: 상품 금액 합계가 일정 금액 이상이면 무료 (기준 금액은 기획이 정한다)
- 새로고침해도 장바구니가 남아 있어야 한다

## 품질

- 금액은 원 단위, 천 단위 쉼표 (예: 12,900원)
- 화면 폭이 좁아도(모바일) 쓸 수 있어야 한다
- 수량은 1 이상, 상품별 최대 수량은 기획이 정한다

## 산출물

- 기획: `docs/requirements.md` (요건 ID 를 붙인다: REQ-01 …), `design/wireframe.html`
- 개발: `src/` 의 동작하는 화면
- 테스트: `tc/test-cases.md` (TC ID 와 요건 ID 연결), `tests/` 자동 테스트, `backlog.md` 버그
